# Original decision-world illustration

`decision-hk-pixel.webp` is an original generated, pixel-inspired Hong Kong street/counter illustration created for Crossing Lives on 7 October 2026. The side-on composition emphasizes ordinary people using a menu/map, with a generic train symbol, rather than direct-gaze portraits. It is an imagined setting, not a geographic map or a real restaurant quote.

The project owner selected the second composition for one decision-led prototype. No Pixel Shanghai image, character, source code, audio or branded transit art was copied. Pixel Shanghai informed the general idea of scene-attached interaction; this asset is not represented as that site's work or as a rigorously native pixel grid.

- Dimensions: 1672 × 941
- WebP bytes: 1,690,834
- SHA-256: `7f33d0c777b6b9e6856dea66559b19bdb130748685232605ea26efc63e7a3d8a`
- Encoding: lossless WebP; decoded RGBA pixels were checked to match the approved generated PNG exactly
- Suggested image-plane anchors: menu (61%, 62%), map (69%, 65%), phone (76%, 66%)

All legible interface text, route diagrams and controls are semantic HTML/SVG, separate from the illustration. Mobile controls need generous nonoverlapping targets or named alternatives; anchors describe the image plane, not real-world coordinates.
