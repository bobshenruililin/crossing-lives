# Regional map sources

The app uses generalized present-day Natural Earth land/coast geometry and a separate OpenStreetMap-derived Hong Kong–mainland land/river boundary. Place pins are approximate locality anchors, not entrances, district polygons or official planning-centre centroids. The game’s walking route is fictional.

Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/

Boundary data © OpenStreetMap contributors, available under the Open Database License1.0: https://www.openstreetmap.org/copyright

The included hk-mainland-land-border-odbl.geojson preserves the derivative’s source metadata and licence. It is also downloadable from the app when opened offline. See regional-map-source-ledger.md for the dated public evidence and measurement limits. No reference-only government map or screenshot is republished here.
